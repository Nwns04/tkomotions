# TKO Motions — School Demo First Pass

This package contains only the `src/school` demo files.

## First-pass changes
- Reframed the fictional school as Crestfield Academy.
- Updated demo content for the 2026/2027 session.
- Removed stale 2024/2025 dates and obvious dead `#` portal links.
- Removed fabricated university-placement, elite-university, accreditation, and fee claims from key sales pages.
- Reworked admissions into a realistic demo enquiry flow with a demo reference number and WhatsApp continuation.
- Changed public fee display to a request-based fee/enrolment flow.
- Added contextual WhatsApp messages for admissions, tours, fee requests, and checklists.
- Made phone/email actions clickable in key components.
- Reworked curriculum, assessment, and secondary pathways to use adaptable school content rather than invented claims.
- Added a small TKO Motions demo banner on the school homepage.
- Updated school data so the demo is easier to rebrand for a real prospect.

## Install
Replace your existing `src/school` folder with this folder. No files outside `src/school` are included or changed in this package.
